# My Money: сборка iPhone-версии через GitHub (с Windows)

Сборка .ipa идёт в облаке GitHub на Mac-компьютере, поэтому Mac вам не нужен.
Установка на iPhone делается с Windows через Sideloadly.

## Что понадобится

- Компьютер на Windows
- iPhone 15 (iOS 17 или новее)
- Аккаунт на github.com (бесплатный)
- Apple ID, которым вы уже ставили приложения через сертификат
- Программы: Sideloadly (sideloadly.io) и iTunes + iCloud с сайта apple.com (не из Microsoft Store)

## Важно перед началом

В файле `capacitor.config.json` стоит идентификатор `com.example.finance`. Его нельзя менять:
если поменять, приложение установится как второе, и вы не сможете поставить его поверх первой версии.
Если первую версию вы ставили с другим идентификатором, скажите мне, и я поправлю файл под неё.

Виджет баланса в эту сборку не входит: для него нужны ручные действия в Xcode, а Xcode есть только на Mac.
Всё остальное работает: операции, планы, статистика, тёмная тема, английский язык, фото к операциям.

## Шаг 1. Распакуйте архив

Распакуйте `MyMoney-github.zip` на компьютере в обычную папку. Внутри должны быть папки `www`, `native`, `assets`, файлы `setup-ios.sh`, `package.json` и `.github`.

## Шаг 2. Создайте репозиторий на GitHub

1. Войдите на github.com и нажмите **New** (или значок «+» → **New repository**).
2. Название: `my-money`.
3. Выберите **Private** (закрытый).
4. Нажмите **Create repository**.

## Шаг 3. Загрузите файлы

1. В открывшемся репозитории нажмите **uploading an existing file**.
2. Перетащите в окно всё содержимое распакованной папки: `www`, `native`, `assets`, `capacitor.config.json`, `package.json`, `setup-ios.sh`, `.gitignore`, `README.md`.
3. Внизу нажмите **Commit changes**.

Папка `.github` с файлом сборки иногда не загружается перетаскиванием. Если её нет в репозитории:

1. Нажмите **Add file → Create new file**.
2. В поле имени введите `.github/workflows/ios.yml` (GitHub сам создаст папки).
3. Откройте на компьютере файл `.github/workflows/ios.yml`, скопируйте весь текст и вставьте в окно.
4. Нажмите **Commit changes**.

## Шаг 4. Запустите сборку

1. Откройте вкладку **Actions** в репозитории. Если GitHub просит разрешить действия, нажмите **I understand… enable**.
2. Слева выберите **Build iOS IPA**.
3. Нажмите **Run workflow**, затем ещё раз **Run workflow**.
4. Ждите 15–30 минут. Когда напротив запуска появится зелёная галочка, сборка готова.

Сборка запускается только вручную, чтобы не тратить лишние минуты. Для закрытого репозитория на бесплатном аккаунте есть 2000 минут в месяц, но минута на macOS считается как 10 минут, так что хватает примерно на 20 сборок.

## Шаг 5. Скачайте .ipa

1. Откройте готовый запуск (зелёная галочка).
2. Внизу, в разделе **Artifacts**, нажмите **MyMoney-ipa**. Скачается zip-архив.
3. Распакуйте его на компьютере. Внутри файл `MyMoney.ipa`.

## Шаг 6. Установите на iPhone через Sideloadly

1. Установите iTunes и iCloud с apple.com и запустите Sideloadly.
2. Подключите iPhone к компьютеру кабелем. На телефоне нажмите **Доверять** и введите код.
3. На iPhone включите режим разработчика: **Настройки → Конфиденциальность и безопасность → Режим разработчика**, включите и перезагрузите телефон.
4. В Sideloadly выберите ваш iPhone в списке сверху.
5. Перетащите файл `MyMoney.ipa` в окно Sideloadly.
6. Введите ваш Apple ID и пароль, нажмите **Start**.
7. Если Apple попросит код двухфакторной аутентификации, введите его, который придёт на другое ваше устройство.
8. Дождитесь сообщения **Done**.

## Шаг 7. Разрешите запуск на iPhone

1. Откройте **Настройки → Основные → VPN и управление устройством**.
2. В разделе с вашим Apple ID нажмите **Доверять** и подтвердите.
3. Запустите приложение **My Money**.

## Обновление поверх первой версии

Повторите шаги 4–7 с новым `MyMoney.ipa`. Приложение установится поверх старого, а данные обычно сохраняются.
Ничего не удаляйте. Если Sideloadly выдаст ошибку о несовпадении подписи, напишите мне: тогда понадобится другой путь.

## Срок действия установки

- С бесплатным Apple ID установка работает 7 дней. Потом приложение перестанет открываться, и его нужно поставить заново через Sideloadly.
- С платной подпиской Apple Developer (99 $ в год) установка работает год.

## Если сборка упала

Откройте запуск с красным крестиком, нажмите на шаг, который упал, скопируйте последние строки лога и пришлите мне. Я разберу ошибку и поправлю файлы.
